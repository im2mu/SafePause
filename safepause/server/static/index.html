① 동의: 내가 정해요

SafePause가 무엇을 해도 되는지 내가 정해요.

언제든지 끌 수 있어요. 끄면 바로 멈춰요.

  • 거래 살펴보기

    내가 돈을 쓰고 보내는 것을 살펴봐요.

    살펴보는 일은 이 컴퓨터 안에서만 해요.

  • 조력자에게 알리기

    위험이 클 때 내가 고른 조력자에게 알려요.

    누구에게, 언제 알릴지는 ⑤ 조력자에서 정해요.

    이 스위치를 꺼도 직접 물어볼 수 있어요.

    카드에서 '조력자에게 물어볼래요'를 고를 때예요.

  • 상담하는 곳 알려 주기

    상담하는 곳을 알려 줘요.

    지역발달장애인지원센터, 장애인권익옹호기관이에요.

    이럴 때 알려 줘요.

    • 꼭 확인할 일이 30일 동안 3번 이상 생길 때
    • 알릴 조력자가 모두 돈을 받는 사람일 때

    보내지 않고 멈춘 것도 세요.

은행 파일 모양은 따로 확인하지 못했어요. 열 이름을 알아보지 못하면 아래 '열 이름 직접 알려 주기'를 써 주세요.

    ④ 알림 카드

    SafePause가 걱정했던 거래예요. 최근 것부터 보여요.

    내가 고른 것

    보내기 연습에서 내가 고른 것을 기록해요.

      ⑤ 조력자

      조력자는 내가 믿는 사람이에요. 누구에게, 언제 알릴지 내가 정해요.

      조력자가 돈을 받는 사람이면 그 조력자에게는 알리지 않아요.

      다른 조력자에게만 알려요.

      알릴 조력자가 없을 때도 있어요.

      그때는 상담하는 곳을 알려 줘요.

      ① 동의에서 '상담하는 곳 알려 주기'를 켰을 때만이에요.

      조력자 알림 기록

      알림은 기록만 해요. 이 컴퓨터에 적어 두고, 문자나 메일은 보내지 않아요.

        ⑥ 성능 확인

        합성 데이터 기준, 실제 피해 데이터 검증 아님

        가상의 거래에 걱정되는 거래를 섞어서, SafePause가 얼마나 찾는지 확인해요.

        어떤 방식으로 확인할까요?

        내 거래로 확인
