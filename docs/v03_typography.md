# SafePause v0.3 화면 글 정리 기준 (줄 간격·문단 나눔, 2026-10-03 사용자 요청)

사용자 요청: "줄 간격, 문단 나눔 등 좀 더 깔끔하게 최적화"(대상: 앱 화면 글).
'한 문장 한 줄'(R18)은 유지한다. 그 위에서 토스처럼 읽기 쉬운 리듬을 만든다.

## 1. 원칙

1. **문장 간격 < 문단 간격 < 구역 간격**
   - 같은 문단 안 문장은 촘촘하게(.15rem), 문단 사이는 분명하게(.6~.75rem), 구역 사이는 크게(1.5rem 이상) 띄운다.
   - 지금은 한 문장짜리 `<p>`가 여러 개 이어져 모든 줄 간격이 같아 덩어리가 보이지 않는다.
2. **관련 문장은 한 문단으로 묶는다.**
   - 같은 내용을 설명하는 2~3문장은 `<p>` 하나에 넣는다. ui.h가 문장마다 줄을 나눈다.
   - 다른 내용이면 문단을 나눈다.
   - 한 문장짜리 `<p>`를 줄줄이 쓰지 않는다.
3. **줄 높이는 글 종류마다 하나로 정한다.**
   - 본문 1.6, 보조글 1.55, 제목 1.3, 큰 숫자 1.2, 버튼·칩·배지 1.3
4. **줄 끝에 한두 글자만 남지 않게 한다.**
   - 문장은 `text-wrap: pretty`, 제목·짧은 이름표는 `balance`를 쓴다. `word-break: keep-all`은 유지한다.
   - 숫자+단위·시각·금액은 끊기지 않는 묶음(`.nowrap`)으로 둔다.
5. **글 폭**: 넓은 화면에서 설명 글은 34em 안쪽으로 둔다. 한 줄이 너무 길면 읽기 어렵다.
6. **군더더기를 줄인다.**
   - 같은 화면에서 같은 말을 되풀이하는 문장, 제목을 그대로 풀어 쓴 첫 문장은 뺀다.
   - 필수 문장(tests/test_static_ui.py 목록)과 사실 안내는 남긴다.
   - 한 화면 설명 글은 3문장 안쪽을 목표로 한다.
7. **배치 일관성**
   - 카드: 안쪽 여백 1.25rem, 제목 → 본문 .35rem, 본문 → 버튼 1rem
   - 안내 상자(.notice): 아이콘을 첫 줄 가운데에 맞춘다.
   - 목록(li): 간격 .35rem, 들여쓰기 하나로
   - 시트: 제목 → 부제 .4rem, 부제 → 내용 1.1rem
8. **간격 토큰**: `--space-1 .25rem / -2 .5rem / -3 .75rem / -4 1rem / -5 1.5rem / -6 2rem`. 새 규칙은 토큰만 쓴다.

## 2. 구현

- app.css
  - 간격 토큰을 둔다.
  - `.sent + .sent{margin-top:.15rem}`, `p + p{margin-top:.6rem}`(문단), 카드·시트·안내 상자 안 마지막 요소 아래 여백 0
  - 줄 높이 체계를 위 3번대로 맞추고, 넓은 화면 글 폭을 34em으로 둔다.
  - 기존 규칙과 겹치면 하나로 합친다(중복·상충 규칙 정리).
- ui.h
  - 문장 나누기는 그대로다.
  - 버튼·칩·배지·토스트 안 글은 나누지 않거나 촘촘하게 둔다(한 줄에 들어가면 한 줄).
- 화면 파일: 한 문장짜리 `<p>` 줄줄이를 의미 단위 문단으로 묶는다. 문구를 줄일 때는 사실·필수 문장을 지킨다.

## 4. 구현 결과(2026-10-03)

### 4.1 CSS 체계(app.css 한 파일로 정리)

- app.css를 차례(1 토큰 · 2 기본 · 3 글 · 4 앱 틀 · 5 카드·목록 · 6 배지·칩 · 7 버튼 · 8 입력 · 9 안내 상자 · 10 표 · 11 시트 · 12 화면 부품 · 13 v0.3 부품 · 14 화면 크기별)대로 다시 썼다.
  - 같은 선택자를 여러 번 덮어쓰던 규칙(`.row`·`.row-icon`·`.row-main`·`.card`·`.notice`·`.switch`·`.btn-row`·`.badge`·`.chip`·`--gutter`·`--nav-h` 등, "2차 검증 반영"·"v0.3 수정" 덧붙임)을 마지막에 이기던 값 하나로 합쳤다.
  - 쓰지 않는 규칙(`.stats`·`.stat`·`.metric`·`.meter`·`.small`·`.xs`·`.divider`·`.sk-line`)과 `!important`(목록 표시 줄)를 뺐다.
- 토큰
  - 간격: `--space-1~6`(.25·.5·.75·1·1.5·2rem)
  - 글 리듬: `--gap-sent .15rem` < `--gap-list .35rem` < `--gap-para .6rem` < `--gap-section 1.5rem`, `--gap-block`·`--gap-action`·`--pad-card 1.25rem`·`--gap-sheet-title .4rem`·`--gap-sheet-sub 1.1rem`·`--indent`
  - 줄 높이: `--lh-body 1.6`·`--lh-sub 1.55`·`--lh-title 1.3`·`--lh-num 1.2`·`--lh-ui 1.3`. 화면별 CSS에 흩어져 있던 1.25·1.35·1.4·1.45 값을 모두 토큰으로 바꿨다(한 글자 상자의 `1`만 남김).
  - 글 폭: `--measure 34em`(`p { max-width }`)
  - 목록 줄: `--ic-row min(2.4rem, 10vw, 56px)`·`--gap-row`·`--pad-row`(넓은 화면 큰 글씨에서 그림이 96px까지 커지던 것을 56px에서 멈춤)
- 리듬 규칙: `.sent + .sent`(.15rem), `p + p`(.6rem), `.section-title` 앞(1.5rem). 카드 제목 → 본문 .35rem, 카드 본문 → 버튼 1rem(`.card > :is(.btn, .btn-row, .card-actions)`), 카드·안내 상자·목록·시트 안 마지막 요소 아래 여백 0. 시트 제목 → 부제 .4rem, 부제 → 내용 1.1rem, 내용 → 버튼 1.5rem.
- 안내 상자·아이콘 줄: 아이콘을 `margin-top: max(0px, calc((1lh - 아이콘) / 2))`로 첫 줄 가운데에 맞춘다(안내 상자·조력자 안내·결과 필수 문장·은행 앱 안내·받는 사람 경고·못 쓰는 방법 이유·지금 할 수 있는 일·묶음 머리·AI 설명·약속 셋·엔진 띠).
- 점 목록: `.bullets`(`.about-bullets`·`.consent-bullets`·`.notice ul`)는 들여쓰기 하나(`--indent`), 항목 사이 .35rem.
- 줄바꿈: 문장 `text-wrap: pretty`, 제목·이름표·배지·칩·버튼·`b`·`strong` `balance`. `.row-title`은 잘라 쓰지 않고 줄을 바꾼다(큰 글씨에서 이름·추천 배지가 잘리던 문제).

### 4.2 글 넣기(ui.js·components.js)

- `keepNodes(text)`: p의 글(setText)과 작은 글 조각(subParts)에서 시각·날짜·금액·`문자·메일`을 `span.nowrap`, 전화번호를 `span.tel-text`(하이픈 뒤에서만 줄바꿈)로 묶는다. 금액 바로 뒤 한글 세 글자 이상(`63만7천원이었어요`)과 긴 기관 이름(`장애인권익 / 옹호기관`) 사이에는 `wbr`을 둔다. `textContent`는 그대로다.
- `subParts`는 조각 전체를 줄 바꾸지 않는 빈칸으로 만들던 것을 그만두었다. 조각이 칸보다 길면 묶음 사이에서만 줄을 바꾼다(전에는 넘쳐서 `2026년 6월 25일 (` / `목)`, `모두 720,000` / `원`처럼 잘렸다).
- `breakableEmail`은 `@` 앞과 도메인 점 뒤(남는 글이 세 글자 이상일 때만)에서 줄을 바꿀 수 있게 했다.
- `paragraphs(lines)`: 문장 목록을 문단으로 묶는다. `confirmSheet`·`comingSoonSheet`·동의·첫 실행이 쓴다.

### 4.3 문단 묶기·군더더기(화면 파일)

- 한 문장짜리 p 줄줄이를 의미 단위 문단으로 묶었다: 확인 창·준비 중 시트(공용 함수), 동의·첫 실행 설명, 조력자·상담하는 곳의 동의 꺼짐 안내와 조력자 원칙 안내, 돈 보내기 결과 글·적어 둔 기록 안내·물어볼 조력자 없음, 알림 요약, 결과 내보내기 카드, AI와 데이터 설명(학습 데이터·개인정보), 사용법 안내 단계.
- 문구를 줄이거나 바로잡은 곳(사실·필수 문장 유지)
  - 동의·첫 실행·조력자 화면의 조력자 알림 설명을 실제 동작(조력자 설정에 맞는 사람을 미리 골라 두고, 돈 보내기에서 걱정되는 거래를 확인하면 적어 둠, 보내기는 본인이 문자·메일 앱에서)과 맞췄다. 꼭 확인할 거래만이라고 쓰던 것을 걱정되는 거래로(조력자마다 알릴 등급을 고름).
  - 상담하는 곳 동의 설명: 알릴 때가 되면 알림 탭에서 알려 드리고, 알림 보내기에서 상담하는 곳을 추천한다고 구체적으로 썼다.
  - 홈 요약 카드: 지난달 같은 기간 값(5월 1~29일에 나간 돈)을 목록 첫 줄에서 빼 비교 문장과 한 문단으로 옮겼다. 목록에는 기준 달 값만 남는다.
  - 알림 같은 일 묶음 머리: 카드 줄의 7일 동안 모두(약속 기준 합계)와 헷갈리지 않게 묶음 합계를 더하면 …원으로 썼다.
