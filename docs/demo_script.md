# 데모 영상 대본 (v0.2, 약 4분)

준비: 휴대폰에 `SafePause-0.2.0.apk`를 설치하고 한 번 켜서 AI 엔진 준비(약 10초)를 마친 상태에서 녹화를 시작합니다.
처음 상태를 보여 주려면 '전체 → 내 데이터 → 모두 지우기' 뒤 앱을 다시 켭니다(첫 실행 안내부터 나옴).
휴대폰 화면 녹화(안드로이드 빠른 설정의 '화면 녹화')를 쓰고, 소리로 듣기 장면이 있으면 '미디어 소리 녹음'을 켭니다.
PC로 찍을 때는 `SafePause.exe`로 연 브라우저 창을 휴대폰 폭(개발자 도구의 기기 모드 등)으로 줄이면 같은 화면입니다.

영상 첫 화면과 끝 화면에 자막: "연습 화면 · 실제 송금 없음", "성능 수치는 합성 데이터 기준, 실제 피해 데이터 검증 아님".
화면 문구는 실제 앱 문구를 그대로 씁니다. 각 장면과 제안서 대응은 README 4장(내레이션에서는 읽지 않음).

주의:

- 화면의 숫자(건수·비율)는 seed와 선택에 따라 다를 수 있습니다. 성능은 'AI 성능 확인'의 제출 보고서 수치 표
  (원자료 `docs/eval/eval_results_holdout.json`)를 인용합니다.
- '소리로 듣기'는 기기에 한국어 음성(인터넷이 필요 없는 음성)이 있을 때만 보입니다.
- 9.6만 → 6.7만 원은 검증 세트(seed 21~40) 표준 시나리오에서 두 방식 모두 시나리오 300개를 전부 찾은 조건의 '첫 카드 전 평균 유출'입니다.
