# 데모 영상 대본 (v0.3, 약 4분)

준비: 휴대폰에 `SafePause-0.3.0.apk`를 설치하고 한 번 켜서 AI 엔진 준비(약 10초)를 마친 상태에서 녹화를 시작합니다.
처음 상태를 보여 주려면 '전체 → 동의 → 모두 지우기'(맨 아래) 뒤 앱을 다시 켭니다(첫 실행 안내부터 나옴).
휴대폰 화면 녹화(안드로이드 빠른 설정의 '화면 녹화')를 쓰고, 소리로 듣기 장면이 있으면 '미디어 소리 녹음'을 켭니다.
조력자 한 명(전화번호 포함)과 상담하는 곳 한 곳을 미리 저장해 두면 알림 보내기 장면이 짧아집니다.
PC로 찍을 때는 `run_windows.bat`(README 1장 ① 소스 실행)로 연 브라우저 창을 휴대폰 폭으로 줄이면 같은 화면이지만, 문자·전화·내 은행 앱 열기 대신 메일과 안내만 나옵니다.

영상 첫 화면과 끝 화면에 자막: "SafePause는 돈을 보내지 않아요 · 보내기는 내 은행 앱에서", "성능 수치는 합성 데이터 기준, 실제 피해 데이터 검증 아님".
화면 문구는 실제 앱 문구를 그대로 씁니다. 각 장면과 제안서 대응은 README 4장(내레이션에서는 읽지 않음).

주의:

- 화면의 숫자(건수·비율)는 번호와 선택에 따라 다를 수 있습니다. 연습용 거래 기본값(가상 근로자·번호 10)에서는 거래 222건이고,
  AI만 먼저 찾은 거래가 1건(6월 17일 새벽 김*호 28만 원) 있습니다. 성능은 'AI 성능 확인'의 제출 보고서 수치 표
  (원자료 `docs/eval/eval_results_holdout.json`)를 인용합니다.
- '소리로 듣기'는 기기에 한국어 음성(인터넷이 필요 없는 음성)이 있을 때만 보입니다.
- 9만 6천 원 → 6만 7천 원은 검증 세트(seed 21~40) 표준 시나리오의 '첫 알림 전 평균 유출'입니다.
- 같은 화면의 보고서 수치 다시 계산은 앱 안 엔진이 검증 세트를 실제로 다시 계산해 보고서 수치와 같은지 보여 줍니다.
  시간이 걸려(PC 서버 약 21~23초, 앱 묶음을 PC의 Chrome에서 약 43초, 에뮬레이터 약 66~89초, 휴대폰은 재지 않음) 위 4분 표에는 넣지 않았습니다.
  넣으려면 녹화 전에 이 화면에서 눌러 끝까지 기다린 뒤 결론 줄(다시 계산한 값이 보고서 수치와 모두 같아요.)을 보여 줍니다. 다른 화면으로 가면 결과를 버립니다.
- 실제로 문자를 보내지 않으려면 문자 앱이 열린 뒤 뒤로 가기로 돌아옵니다. SafePause는 보낸 알림에 기록만 남깁니다.
