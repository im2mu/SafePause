# 데모 영상 대본 (약 4분)

준비: `SafePause.exe`를 더블클릭(또는 `run_windows.bat`, `python -m safepause serve`)해 화면을 연 상태. 처음이면 ⑦에서 모두 지우고 시작합니다.
화면 문구는 실제 프로그램 문구를 그대로 씁니다. 각 장면이 제안서의 어느 내용에 해당하는지는 README 4장 대응표를 보세요(내레이션에서는 읽지 않음). 영상 첫 화면과 끝 화면에 "연습 화면, 실제 송금 없음"과
"성능 수치는 합성 데이터 기준, 실제 피해 데이터 검증 아님"을 자막으로 넣습니다.

| 시간 | 화면 | 내레이션(예시) |
|---|---|---|
| 0:00–0:20 | 첫 화면(머리의 "연습 화면이에요. 실제로 돈이 나가지 않아요.") | "「2024 장애인학대 현황보고서」에서 학대 인정 사례의 18.6%(384건)가 경제적 착취였고, 피해자의 71.1%는 발달장애인이었습니다. 지금 제도는 돈이 나간 뒤에야 움직입니다. SafePause는 돈이 나가기 전에 잠깐 멈추게 돕습니다. 막지 않고, 결정은 당사자가 합니다. 모든 판단은 이 컴퓨터 안에서만 합니다." |
| 0:20–0:45 | ① 동의: '거래 살펴보기', '조력자에게 알리기', '상담하는 곳 알려 주기'를 하나씩 켬 | "무엇을 해도 되는지 당사자가 정합니다. 세 가지를 따로 켜고 끄며, 끄면 바로 멈춥니다." |
| 0:45–1:10 | ② 내 거래: 가상 근로자 + 걱정되는 거래 섞기 → 불러오기, '꼭 확인할 것만' | "가상 인물의 합성 거래입니다. 거래마다 괜찮아요, 확인해요, 꼭 확인해요와 이유가 붙습니다. 규칙 5가지와 본인 기준 AI를 함께 씁니다." |
| 1:10–1:35 | ⑤ 조력자: 엄마(모든 것), 아빠(휴대폰 요금이 여러 개만) 저장, 연락처가 가려져 저장되는 모습 | "조력자와 알릴 범위도 당사자가 정합니다. 기본은 꼭 확인할 때만 알립니다. 조력자가 돈을 받는 사람이면 그 사람에게는 알리지 않습니다. 이 규칙은 제안서에는 없고 질의 답변서에서 보완한 것입니다." |
| 1:35–2:30 | ③ 보내기 연습: '김*호에게 30만 원 (새벽 2시)' → 보내기 → 안전 정지 카드, '소리로 듣기' | "새벽에 30만 원을 보내려 하자 카드가 뜹니다. 이 데이터에서는 요즘 밤늦게 여러 번 보낸 기록이 있어 '밤에 돈을 자주 보냈어요'라고 알려 줍니다. 그림과 짧은 문장으로 이유를 말하고, 정말 보낼지 묻습니다. 고르기 전에 누가 알게 되는지도 보여 줍니다." |
| 2:30–3:00 | '조력자에게 물어볼래요' → 물어볼 사람 고르기 → '체크한 사람에게 물어볼래요' → 결과 화면 | "물어볼 사람도 당사자가 직접 고릅니다. 엄마는 ⑤에서 '꼭 확인할 때만 (처음 설정)'으로 정해 두어서 체크가 고정되어 있고, 그 까닭이 화면에 적혀 있습니다. 알림은 이 컴퓨터에 기록만 되고, 문자나 메일은 보내지 않습니다." |
| 3:00–3:20 | 같은 예시로 '그래도 보낼래요' → "보냈어요 (연습)" | "그래도 보내겠다고 하면 그대로 진행됩니다. 잘못 알린 경우에도 당사자의 결정을 막지 않습니다." |
| 3:20–3:45 | ⑥ 성능 확인: 3가지 방식 → 확인 시작, 표 | "합성 데이터로 규칙, AI, 둘을 합친 방식을 비교합니다. AI는 규칙이 아직 못 본 출금에 먼저 카드를 띄웁니다. 그래서 첫 카드가 뜨기 전에 나간 돈이 평균 9.6만 원에서 6.7만 원으로 줄었습니다(규칙 보완에 쓰지 않은 검증 seed 21~40, eval_report 7절). 모두 합성 데이터 기준이며 실제 피해 데이터로 검증한 값이 아닙니다." |
| 3:45–4:00 | ⑦ 내 데이터 지우기 → 네, 지울래요 | "언제든 모든 데이터를 지울 수 있습니다. 즉시 철회권입니다." |

대체 장면(명령행, 10초): `python -m safepause demo` 출력에서 카드와 "조력자: 엄마에게 알려 드릴게요. (알림 대상 1명, 데모라 기록하지 않음)" 줄을 보여 줍니다.
데모 명령은 아무것도 저장하지 않으므로 ⑤ 조력자 알림 기록에는 나오지 않습니다(기록은 화면에서 고른 결과만).

주의:

- 화면의 숫자(건수·비율)는 seed와 선택에 따라 다를 수 있습니다. 영상에 나온 숫자를 성능으로 소개하지 말고,
  성능은 [eval/eval_report.md](eval/eval_report.md)의 20-seed 결과를 인용합니다.
- '소리로 듣기'는 녹화하는 컴퓨터에 한국어 음성(Windows의 한국어 음성 등)이 있을 때만 보입니다.
